# Sound Effects

Made by Brandon Blodget using jsfxr ([https://sfxr.me/](https://sfxr.me/)),
Chris McCormick's JavaScript port of DrPetter's sfxr.

All files are 16-bit mono WAV at 44.1 kHz.

| File | Plays when | jsfxr preset |
|---|---|---|
| jump.wav | the player jumps | Jump |
| lash.wav | the player lashes to a wall | Laser/Shoot |
| land.wav | the player lands on a surface | Hit/Hurt |
| coin.wav | a coin is collected | Pickup/Coin |
| gate.wav | the gate opens (all coins collected) | Powerup |
| fall.wav | the player falls out of the hall | Synth |
| parMissed.wav | the player touches the gate after par | Powerup |
| parBeat.wav | the player touches the gate at or under par | Powerup |
